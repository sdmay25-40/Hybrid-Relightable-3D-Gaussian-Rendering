Built on Unity Editor Version 2022.3.50f1

Hybrid Relightable 3D Gaussian Rendering

Overview:
It is a program that generates high quality 3D models from videos using neural 3D Gaussian Splatting and the Unity pipeline.

Prerequisites before use:

    Must have Unity installed on your computer.
    Must have an Nvidia's graphics card in your computer.

How to use:
   1) Download our project from the Asset Store
   2) Add it to your project? //Or is it a project
   3) Make sure you have python 3.14 installed
     3.1) Here is a link to download python: https://www.python.org/downloads/
   4) Take the video files you have and drag them to the BLANK folder in the unity project folder.
   5) Hit play in Unity, this may take a while depending on the length of your video. The generated 3D model should be outputted to the BLANK folder.
